### Crud

Консольное приложение для управления каталогом автомобилей, разработанное на TypeScript. Приложение позволяет добавлять, просматривать, редактировать и удалять записи об автомобилях через интуитивно понятное интерактивное меню.

### ✨ Возможности

| Функция | Описание |
|---------|----------|
| ➕ Добавление | Создание новых записей с валидацией данных |
| 📋 Просмотр | Отображение всех автомобилей в формате таблицы |
| 🔍 Поиск | Поиск по производителю или модели |
| 📊 Сортировка | Сортировка по цене, году выпуска или ID |
| ✏️ Редактирование | Обновление данных существующих автомобилей |
| 🗑️ Удаление | Удаление записей с подтверждением |
| 👁️ Детали | Просмотр подробной информации об автомобиле |
| 💾 Сохранение | Автоматическое сохранение данных в JSON-файл |
| 🎨 Интерфейс | Цветной вывод с использованием Chalk |
